# LRM × Li₃PO₄ 计算成果展示网页

这是一个无构建、无依赖的静态单页网页。页面引用上级目录中的差分电荷、DOS/PDOS 图像，以及已有 Markdown 报告和 `delta_rho.cube` 文件。

## 打开方式

在项目根目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:8765/project_results_web/
```

也可以使用 Codex 的浏览器面板打开该地址。建议通过本地 HTTP 服务打开，避免浏览器对 `file://` 下的相对路径、中文报告和大体积 cube 文件做额外限制。

## 文件说明

- `index.html`：页面结构、数据和结论文本
- `styles.css`：响应式布局和科研 dashboard 视觉样式
- `app.js`：图像灯箱放大交互
- `report-additions.css`：计算方案和 Mulliken 结果章节的样式
- `docs/LRM-LPO_ABACUS_plan.md`：用户上传的计算方案原文副本
